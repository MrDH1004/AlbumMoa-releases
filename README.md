# 앨범모아 (AlbumMoa) — 설치 파일

우리 아이의 **사진·동영상·알림장 글**을 기간을 정해 내 PC로 한 번에 내려받는 Windows 프로그램입니다.
키즈노트에서 사용합니다.

## 내려받기

**[최신 버전 설치 파일 받기 →](../../releases/latest)**

`AlbumMoa-x.y.z-setup.exe` 를 받아 실행하면 설치됩니다. 관리자 권한은 필요 없습니다.

- 설치 후에는 프로그램을 켤 때마다 새 버전을 확인하고, 새 버전이 있으면 **자동으로 업데이트**합니다.
- 처음 실행할 때 Windows가 "PC를 보호했습니다" 경고를 띄울 수 있습니다.
  서명되지 않은 프로그램이라 나타나는 안내이며, **추가 정보 → 실행**을 누르면 됩니다.

> **무료 · 광고 없음 · 개인 백업용**
>
> 이 프로그램은 **(주)키즈노트와 아무런 관련이 없는 비공식 프로그램**입니다.
> '키즈노트'는 (주)키즈노트의 상표이며, 어떤 서비스에서 쓰는 도구인지 밝히기 위해서만 표기했습니다.
> 본인 계정에 등록된 **본인 자녀의 자료를 개인적으로 백업**하는 용도로만 사용하세요.
